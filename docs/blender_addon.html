Blender add-on¶

The add-on is a pure importer. It reads a unified dataset (manifest + cells.csv + per-type GeoJSONs) and builds the Blender scene. It does no downloading and no geometry processing – all of that is the pipeline’s job (How the pipeline works). This keeps the add-on small: it ships only the importer, plus version.py and unified.py.

  • Location: View3D > Sidebar (N) > Apian tab.

  • Minimum Blender: 5.2 (LTS).

  • Runtime dependencies inside Blender: numpy and scipy. The zip also vendors h3 and shapely (cp313 wheels) so subset import can clip features to the selected-cell outline inside Blender’s bundled Python.

Install and dependencies¶

Build and install the zip as described in Installation (python build_addon.py -> dist/apian_terrain.zip -> Blender’s Install add-on dialog).

If numpy/scipy are missing from Blender’s Python, the panel shows a Missing dependencies box with an Install Dependencies button. It runs ensurepip and pip-installs the required packages into Blender’s per-version user-modules directory. Restart Blender afterwards.

The panel header shows the running Apian vX.Y.Z so you can tell at a glance whether Blender loaded a fresh build or a stale install.

Panel reference¶

The tab is a single parent panel with a pinned header (the running Apian Terrain vX.Y.Z version label, plus the Missing dependencies box when numpy/scipy are absent) followed by collapsible child sections:

  1. Setup – one-off Install Node Groups and Shaders button (the dev add-on expects the node groups in the .blend instead).

  2. Metadata – the region manifest / subset picks (below).

  3. Scale – import scale, vertical scale and the floor/base-pad box.

  4. Terrain – Terrain Centres and Surface import/purge rows. The surface is always built with the simple interpolated topology.

  5. Features – the Projection Target picker, then per-layer rows: Streets, Structures, Contour Lines, Landmarks (with the landmark display controls nested underneath), and Custom GeoJSON.

  6. Data – the Data Carrier import/purge row. The carrier is rebuilt from the manifest’s data layers and clones the Terrain Centres mesh 1:1, so Centres must be imported first.

Config¶

The add-on is a pure importer of the unified dataset. It has no shared config file; pipeline reference paths live in the companion app’s Global Inputs panel and are baked into the manifest.

Metadata¶

Control

Meaning

Name

Area identifier; also the imported collection’s name (used by Purge Area).

Into Collection

Parent collection for the import (blank = scene root).

Region Manifest

Pick the <area>_manifest.json (the region folder under Regions\). cells.csv is read from the same folder; the per-type GeoJSONs come from the region’s output\ subfolder.

Region Subset

Optional <name>_subset.json – the importer resolves its region and clips cells and features to the selected cells (see The unified dataset format, “Subset manifests”).

Data layers (cell_field) ship for the beta. The importer bakes each declared field onto the area’s Data Carrier (a 1:1 clone of the Terrain Centres point mesh) as data_<field> FLOAT plus a data_<field>_present BOOLEAN mask. The bundled Geometry Nodes groups (APIAN_TERRAIN_CENTRES, APIAN_TERRAIN_SURFACE) sample the carrier by cell index: the importer sets Data Carrier / Data Field / Field Min / Field Max on the modifier and the groups expose Data Factor (normalized value, 0 when absent) and Data Present (0/1, so a real 0 is distinguishable from no data). Blender 5.2 cannot name attributes dynamically in node trees, so the groups read the carrier’s default field (_data_value); switching fields is a post-beta item. Per-frame cell_series playback repaints the carrier’s _data_value/_data_value_present attributes every frame over the series’ time range. An empty carrier is inert: the groups guard on the carrier’s point count and simply read no data.

Scale¶

Control

Meaning

Clear Existing

Delete existing terrain objects before importing.

Longest Edge (m)

Target Blender size of the bbox’s longest edge. Scale is derived from this so every area imports at a consistent size.

Vertical Scale

Vertical exaggeration (1.0 = true scale).

Floor / base pad¶

The base plane below the lowest terrain, recomputed live at every import from the dataset’s own cell min/max: base = floor - factor x (max - min).

The dataset’s baked ele_min_baked_m only survives as a fallback for datasets without cell data.

Feature layers¶

The Features section starts with the Projection Target picker (choose the mesh the feature layers project onto; an INFO hint shows while it is None), then one row per layer with its own Import / Purge buttons. Purging is deferred to a timer (off the viewport draw path) and shows a progress bar while running.

Layer row

Controls

Streets

Layer filter (All / Major Roads / Highways) + projection (XY / Target), Import / Purge.

Structures

Layer filter (All / Notable Structures and Bridges / Bridges Only / None) + projection, Import / Purge, and a Group By split (borough / suburb / usage).

Contour Lines

Import / Purge only. The pipeline’s contour segments are welded into one edge mesh, styled by _level_m / _is_major.

Landmarks

Import / Purge only. The landmark display controls (Visible level-of-detail slider, text rotation / scale / Z offset, marker scale / pole thickness and overall landmark scale) sit in a nested box under the row.

Custom GeoJSON

Clear-existing checkbox + projection (Flat / Target), Import / Purge, and the file picker. Imports a custom GeoJSON of LineString / MultiLineString features as one curve object in the current area’s local frame.

Actions¶

  • Import – build the scene from the selected dataset.

  • Purge Area – delete the Blender collection for the current area (by name, or by walking up the active object’s parent tree), then purge orphans.

  • Assign Reference to Collection – copy the selected imported structure’s id onto the active collection’s osm_id property, so that collection is instanced as the reference model for that structure. (Select the imported structure, make your reference collection active in the Outliner, then click.)

  • Import Custom GeoJSON – import a custom GeoJSON of LineString / MultiLineString features as one curve object (a spline per feature) in the current area’s local frame. Two projection behaviours per import: Flat (the coordinates’ own Z, or 0) or Project to Surface (each resampled point raycast down onto the area’s terrain surface; off-terrain points stay flat and are reported). The object is named <area> - <file>, parents under the area root, and keeps the per-feature names in its feature_names property.

Operators¶

Every button maps to an operator you can also call from scripts or search:

Sun & Sky¶

The panel’s Sun & Sky section drives a real-ephemeris sky from the imported area’s location (auto-filled from the manifest origin; editable). The positions come from apian_terrain.celestial – Paul Schlyter’s low-precision ephemeris, dependency-free and unit-tested; plenty for lighting at hourly granularity.

  • Date and Solar time – the moment to light. Times are local solar time: 12:00 is solar noon for the area’s longitude, not wall-clock time (this matches render_headless.py’s --time).

  • Sun / Moon size and strength, Night sky, North offset – the rig’s creative controls.

  • Atmosphere (daytime) – air, dust, ozone and altitude for the sky texture.

  • Setup Sun & Sky – build (or update) the rig.

  • Bake Day / Purge Bake – keyframe the sun/sky across the day at the chosen bake step, with auto exposure (separate day EV and night lift) compensating as the sun drops; Purge Bake removes the bake.

Preferences¶

Under Edit > Preferences > Add-ons > Apian, the add-on preferences are minimal: the add-on is a pure importer of the unified dataset. All reference-data paths and keys belong to the companion app’s Global Inputs panel (see Configuration) and are baked into the manifest at build time. * Custom Unified Terrain Dir (dem_tile_dir) * Custom Topography Dir (topo_tile_dir) * Custom Bathymetry Dir (bathy_tile_dir) * OpenTopography API Key (opentopography_api_key)

How import scaling works¶

The importer reads the area block from the manifest (bbox + elevation range), converts the bbox’s longest edge to metres, and derives SCALE so the longest edge maps to Longest Edge (m) Blender units. Vertical scale is then applied on top. The practical effect: areas of different real-world size all arrive at a comparable on-screen size, and you control that size with one field.
