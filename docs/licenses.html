Data licensing¶

Apian is built so that a customer using the standard installation never has to think about data licenses. This page explains how that works, and where the edges are. The machine-readable notices live in the NOTICE file shipped with the app and the add-on, and every dataset the pipeline writes carries its own attribution in the manifest (<area>_manifest.json, key attribution).

The short version¶

  • Using Apian, and selling/sharing scenes, renders, images or animations made with it: fine. Every data source in the standard pipeline permits commercial use. The required credit lines are collected for you in NOTICE and in each dataset’s manifest.

  • Redistributing an Apian *dataset* (the manifest + cells.csv + GeoJSONs themselves): allowed, but the OpenStreetMap- and OpenBuildingMap-derived parts stay under the ODbL, which requires attribution and share-alike on the database. This cannot be licensed away – it is inherent to using OSM-derived building/street/water data. A rendered scene is a “produced work” and is not share-alike; the underlying database is.

  • Bringing your own custom data (Custom data): your license, your responsibility – the app adds no terms to it.

How the attribution follows the data¶

The pipeline writes an attribution block into every dataset manifest it produces. The block lists each source, its license, and the credit string, so whatever the dataset is used for – imported into Blender, handed to a colleague, shipped in a game – the required credits travel with it. The NOTICE file installed alongside the app contains the same list for the standard pipeline as a whole.

The satellite colour source¶

Per-cell surface colour and the Image Texture default to Sentinel-2 L2A true-colour imagery, fetched as Web-Mercator tiles from the Microsoft Planetary Computer mosaic API over the public Copernicus archive. Sentinel data is free, full and open for any use – including commercial – so the default colour layer carries no licensing ambiguity. The trade-off is ground resolution: Sentinel-2 is 10 m/px natively, so fine texture detail is softer than commercial imagery. The credit line (“Contains modified Copernicus Sentinel data”) is carried in NOTICE and every dataset manifest.

Software licenses¶

Apian is GPL-3.0-or-later (the Blender Python API makes GPL the natural fit, and the add-on ships the full license text). The add-on zip vendors h3 (Apache-2.0) and shapely (BSD-3-Clause) so the importer works inside Blender’s bundled Python; their license texts are inside apian_terrain/_vendor/*/dist-info/licenses/. The frozen companion app bundles the usual scientific-Python stack under their permissive licenses; see NOTICE.
